# ♟ Лендинг шахматного мероприятия

Адаптивная вёрстка по макету Figma.  
Live: https://ekvisa.github.io/ChessInVasyuki/

## 🛠 Технологии

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📋 Реализовано

- адаптивная вёрстка
- Pixel Perfect
- бесконечная карусель участников
- автопрокрутка карусели
- бегущая строка
- SVG-анимации
- адаптация под mobile / tablet / desktop

## ✨ Особенности реализации

- карусель реализована без библиотек
- для бесшовной прокрутки используются клонированные элементы
- SVG-текст адаптивно масштабируется вместе с контейнером
- использованы CSS Grid и Flexbox

## 🧩 Кроссбраузерность

Проверено в:
- Chrome
- Firefox
- Opera
- Edge
